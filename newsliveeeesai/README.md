# 📰 Live News App

A responsive live news application built using HTML, CSS, and JavaScript.

## Features
- Fetch live news using NewsAPI
- Search functionality
- Responsive UI
- News cards with images
- Read More links

## Technologies Used
- HTML
- CSS
- JavaScript
- NewsAPI

## API Setup
1. Get API key from https://newsapi.org
2. Replace:
   const apiKey = "296e932c05294076b012b645bd70de34";

## Run Project
Open index.html in browser.

## Deploy on GitHub Pages
1. Push project to GitHub
2. Go to:
   Settings → Pages
3. Source:
   Deploy from branch
4. Branch:
   main
5. Folder:
   /root
6. Save

Your site will be live at:
https://yourusername.github.io/repository-name/
